# College Timetable

A simple and modern college timetable created using HTML and CSS. This project displays a weekly class schedule in a clean and organized table layout.

## Features
- Weekly timetable from Monday to Saturday
- Organized time slots
- Clean and modern UI
- Hover effects on table cells
- Lavender and purple color theme

## Technologies Used
- HTML5
- CSS3

## Repository Structure

```text
College-Timetable/
│
├── index.html
├── style.css
└── README.md
```

## Project Preview
The timetable includes a heading, days of the week, and time slots arranged in a structured table.

## Learning Outcomes
- Understanding HTML table structure
- Styling tables using CSS
- Using Flexbox for layout
- Implementing hover effects and transitions
- Working with colors, spacing, and borders
